# Smart Kabaddi Monitoring System

## Overview
This project introduces a smart sensor-based Kabaddi monitoring system that detects boundary touches and out-of-bounds movements using laser-LDR sensors, ultrasonic sensors, and ESP32 microcontroller technology.

The system helps referees make accurate real-time decisions during Kabaddi matches.

## Problem Statement
Manual refereeing in Kabaddi can lead to:
- Incorrect boundary decisions
- Match disputes
- Human errors during fast gameplay

This project provides a low-cost smart monitoring solution for improving match fairness and transparency.

## Features
- Boundary Detection
- Lobby Monitoring
- Out-of-Bounds Detection
- Real-Time Alerts
- LCD Display Notifications
- IoT Monitoring
- Buzzer Alert System

## Components Used
- ESP32 Development Board

- Ultrasonic Sensors

- Buzzer Module

## Working Principle
The system uses:
- Laser-LDR sensors to detect line interruption
- Ultrasonic sensors to monitor player position
- ESP32 to process decisions
- LCD and buzzer for real-time alerts

Sensor data is also transmitted using WiFi for IoT-based monitoring.
